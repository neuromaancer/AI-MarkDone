## Branch changes since 6.1.0

1. Shared movable annotation editor: nonmodal reading, minimize/expand, explicit
   close/discard, independent recoverable local drafts and stale-write fences.
2. Markdown fidelity: semantic code fences/language, indentation, blank lines,
   inline code, following paragraphs and source-only updates.
3. Rich content: shared compiler and immutable sidecar, readable fallbacks,
   bounded safe SVG/PNG preparation, offline Markdown ZIP with local assets,
   PDF/PNG image-or-placeholder choice, relay hydration and resource cleanup.
4. PDF: isolated same-origin print document, font/image readiness, wide content
   layout and print-scoped asset lifetime.
5. ChatGPT lifecycle: active-page ownership, late body/control admission,
   regeneration identity, visual-only replies and one toolbar per current reply.
6. Unified visual materials over existing tokens: Prompt, Send, export, settings,
   annotation tools, backups, transfer and popup; one modal gutter owner,
   reachable narrow-window actions, keyboard/focus and reduced-motion behavior.
7. Bookmark save tolerates older history prepending while keeping the same exact
   assistant and prompt/body. Marks navigate to their exact reply and passage.
8. Bilingual guidance, fresh-install Directory default preserving existing users,
   version alignment and permanent retirement of Safari-specific code.

## Safari retirement and safety review

Deleted Safari manifests, Vite builds, Xcode/DMG packaging scripts, obsolete
runbook, resource/locale allowlists, UI compile flags and Safari-only tests.
Browser targets and relay origins now admit Chrome/Firefox only. Shared controls
remain available in both; existing feature settings and capability fallbacks stay
in effect. The feedback email subject is browser-neutral. Generic `-webkit-*`
styles and historical release/evidence records remain valid and are preserved.

A failing governance check preceded retirement. Cleanup review caught an
incorrect residual negation in button enablement; six existing real-click tests
reproduced it before correction. The corrected nine-test settings suite passes,
including acknowledged writes, failure recovery, parent disablement and read-only
state. This failed intermediate build is not accepted as the final package.

No new host permissions, active conversation requests, passive observers,
independent content pools or persistence schemas were added. Marks reuse the
existing bounded navigation coordinator and pending-navigation protocol; source
identity is read from stored records by background. Anchor ambiguity fails closed.
